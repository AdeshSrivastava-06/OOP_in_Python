-A constructor is a special method, which is a magic method. We don't have to call the constructor explicitly. It is automatically invoked whenever there is an object made of the class.

-Why it is beneficial ?

All the configuration-related tasks where we don't want the user's input, we put or write it in the constructor. 

Methods are actually handled by the user. If they want to use the method, they can, and if they don't, then they will not. The constructor is different. It is not handled by the user. It is automatically called and executed whenever an object is made of the class.

We can think of it like this: if we are making a website and our website needed a database connection, I will not ask the users' permission for database connectivity. I will write the database connectivity code itself in my constructor so that whenever an object is created, the database connectivity or internet connectivity happens by default.

Inheritance 

-Suppose in an application there are two roles for students and teachers. Now both students and teachers will require login and registration on the website. Creating different classes for both students and teachers for just login and registration violates the protocol, as we are repeating the code. Inheritance allows us to actually make a parent class, and the child class will automatically inherit the attributes and the methods from its parent class. 
-In a class diagram of inheritance, the class inheriting has a sign of a triangle in front of it. 
-DRY - Don't repeat yourself. 

-The things that got inherited are:
- constructor
- non-private attributes
- non-private methods

A child class cannot directly access a parent's private variable.

But a child class can use any parent method (getter, setter, or any other method) that accesses that private variable, because the access is happening inside the parent class's code.


Following points to remember:
- A class can inherit from another class.
- Inheritance improves code reusability.
- Constructor attribute methods get inherited.
- The parent has no access to the child class.
- Private properties of the parent are not accessible directly in the child class.
- The child class can override the attributes or methods. This is called method overriding.
- Super, which is an inbuilt function, is used to invoke the parent class methods and constructors.

POLYMORPHISM 

polymorphism is the ability of an object to take on many forms.
 

Method overriding == is a feature of OOPs that allows a child class to provide a specific implementation of a method that is already defined in its parent class. The implementation in the child class overrides the implementation in the parent class. This is useful when we want to change the behavior of a method in the child class without changing the code of the parent class.

Method overloading == is a feature of OOPs that allows a class to have more than one method with the same name, but with different parameters. The method to be called is determined by the number and type of arguments passed to the method. This is useful when we want to perform different operations based on the number and type of arguments passed to the method.

Operator overloading == is a feature of OOPs that allows us to define the behavior of operators for user-defined classes. For example, we can define the behavior of the + operator for a class that represents a complex number. This way, we can add two complex numbers using the + operator instead of calling a method to add them.


    ABSTRACTION 
    

Abstraction is the process of hiding the implementation details and showing only the functionality to the user. It is achieved by using abstract classes and abstract methods. An abstract class is a class that cannot be instantiated and is meant to be inherited by other classes. An abstract method is a method that is declared in the abstract class but does not have any implementation. The child class that inherits the abstract class must implement the abstract method.

it basically enforecs the child class to implement the abstract method of the parent class then only the child class can be instantiated.It can be written for securrity reasons or to hide the implementation details from the user. It is also used to achieve polymorphism. In Python, we can use the abc module to create abstract classes and abstract methods.
