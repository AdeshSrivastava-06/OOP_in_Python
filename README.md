OOPS in Python

This repository contains Python programs demonstrating the core concepts of Object-Oriented Programming (OOP). It is intended for learning, practice, and understanding how OOP principles are implemented in Python.

Topics Covered
Classes and Objects
Constructors
Instance and Class Variables
Methods
Encapsulation
Inheritance
Polymorphism
Abstraction
Method Overriding
Method Overloading (Python approaches)
Static Methods and Class Methods
Magic (Dunder) Methods

Requirements
Python 3.10 or later
Getting Started


Run any Python file:

python filename.py

Replace filename.py with the name of the program you want to execute.
